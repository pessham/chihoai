# 「AIに優しい人」ほど損をする。雑な思考こそ最高の餌だ

"きれいに整理してからじゃないと、AIに失礼な気がして..."

その“気遣い”が、あなたの成果を削っています。AIにとって最良の餌は、**磨かれる前の混沌**です。未整理の仮説、矛盾する意見、粗いスケッチ。これらを丸ごと投げると、AIは差分を嗅ぎ分け、**尖った答え**を見つけます。

# 雑が強い3つの理由
**1. 情報の多様性が生む飛躍** — 完璧な一次元の指示は、平均的な答えを呼びます。粗い指示は、解釈の幅を生み、**創造的な飛躍**を誘発します。

**2. ノイズが構造を顕在化** — ばらけた断片の中に繰り返し現れる語彙・観点が、**本質的な軸**です。AIはノイズの中から秩序を抽出します。

**3. 比較材料が増える** — あらかじめ“揺れ”を含むと、AIは比較前提で提案します。結果、**意思決定の速度**が上がります。

# 実践：雑に渡すフォーマット
"方向性が3つあって決めきれない... どれも惜しい..."

1) ラフ案A/B/C（各20文字）

2) それぞれの良い点/嫌な点（各1行）

3) 判断基準（優先順位3つ）

4) 禁止事項（言ってはいけないこと/避けたい印象）

→ 「上記の“揺れ”を尊重しつつ、Aの刺激とBの安定を両立する第4案を作成。理由説明も」と依頼します。**AIは“間”を埋めるのが得意**です。

# 事例：キャッチコピーの再設計
"攻めすぎと言われるのは嫌だ... でも印象は残したい..."

- ラフ：A「常識を壊せ」 B「明日が変わる」 C「私の一歩」

- 嫌な点：Aは刺激過多、Bは凡庸、Cは個人主義に寄りすぎ

- 判断基準：新しさ>安心感>個人の主体性

AI提案：**「明日を変える“非常識”を、あなたの一歩から」**（新奇性と安心感を両立）。

# 失敗パターンを避ける心の技法
"きれいにしないと恥ずかしい..." → **恥を道具化**します。「未整理の材料です」と最初に断り、**意図的に荒く**出す。

"矛盾があるとバカにされる..." → **矛盾は素材**です。「意図的に相反する意見を混ぜています」と一言添える。

"まず自分で決めるべき..." → **決めないことで広がる選択肢**があります。初期は“仮同意”に留める。

# まとめ：雑は失礼ではなく、最高の敬意
AIは、あなたの未完成を待っています。**雑は怠慢ではなく、可能性の総量**です。きれいに整える前に、まず投げる。驚くほど“あなたらしい”答えが返ってきます。
