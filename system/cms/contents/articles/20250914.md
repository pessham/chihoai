# 検索をやめても仕事は回る。AIが教えてくれる「情報との付き合い方」

"検索しているうちに、いつの間にか1時間... 結局よく分からない..."

情報過多の時代に必要なのは、**検索の筋力**ではなく**情報との距離感**です。AIと付き合い方を変えるだけで、**情報は“読まれる対象”から“働く資産”**になります。

# 情報は“読む”より“働かせる”
**要点→論点→行動**の順でAIに変換します。

1) 要点：長文の主張/根拠/データ点を抽出。

2) 論点：賛否が分かれる箇所を可視化（反論も出す）。

3) 行動：明日やるべき具体を3つに落とす。

**読む前より、読んだ後を重く**。これだけで、時間の価値が跳ね上がります。

# 情報源の“品揃え”を固定する
"毎回、検索から始まってしまう..."

テーマごとに**信頼できる一次情報の棚**を作り、AIに覚えさせます。省庁データベース、学会誌、社内過去資料など。**棚から選ぶ→AIに要約→比較**の運用に変えると、迷子になりません。

# 事例：新規事業リサーチの時短
"記事は読んだ。で、結局やるのか、やらないのか..."

AIに**出典付き要点→反論→意思決定条件**まで出させ、最後に**“やる/やらない/保留”の判断用チェックリスト**を提示。リサーチ時間は半減し、議論は“判断の根拠”に集中します。

# まとめ：情報に流されず、情報を流す
**情報は海、あなたは船長。** AIは羅針盤です。検索で泳ぎ続けるのではなく、**進む方向を決め、情報に働いてもらう**。それが、今日からの情報との付き合い方です。
