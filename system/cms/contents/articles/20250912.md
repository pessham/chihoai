# 「業務棚卸し」はするな。AI導入は「作業改善」から始まる

"全業務を棚卸ししてから計画を... と思っていたら、半年経っていた..."

大規模棚卸しは達成感はありますが、**成果は先送り**になります。**“1作業の改善”から始める**と、スピードも学習も桁違いに速くなります。

# 単位は“業務”ではなく“作業”
**業務＝目的の集合、作業＝手の動き。** AIは細部で効きます。まず、1日の中で時間を食っている**3〜5分の定型作業**を拾い、**10分で自動化の叩き台**を作ります。

# 作業改善の3ステップ
1) 可視化：画面録画＋口頭解説で“手順”を残す。

2) 生成：AIに手順→スクリプト/テンプレート化を依頼。

3) 導線：ショートカット/メニュー化し、**“押せば出る”**にする。

1作業あたり30分の投資で、毎日5分返ってくるなら、**1ヶ月で黒字**です。

# 事例：見積書の説明文テンプレ化
"毎回、説明文で悩む... 伝わりづらい..."

実運用文をAIに投入→**“骨子テンプレ＋変数”**に変換。担当者は変数を埋めるだけ。**1件あたり6分短縮、クレーム減少**（社内観測）。

# まとめ：小さく始め、積み上げて大きく勝つ
**棚卸しより実装。** まずは今日の“1作業”に手を入れる。**積み上げは雪だるま式**に効きます。半年後、会社の風景が変わります。
