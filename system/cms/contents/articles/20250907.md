# 今日から「メモ帳」を捨てなさい。ChatGPTがあなたの思考を整理する

"メモが増えるほど、頭が散らかっていく..."

書けば書くほど、メモは静かに積み上がり、やがて読まれなくなります。必要なのは蓄積ではなく、**循環**です。ChatGPTを“第二のノート”にし、**書く→要約→再配置→行動**のループを回すと、思考は澄み、前に進みます。

# ノートは「置き場」から「工場」に変える
メモは素材でしかありません。**価値は加工で生まれます**。書いたそばから、AIに以下を実行させます。

- テーマ分類（3～5カテゴリ）

- 重複検知（似たメモの統合）

- 行動抽出（次にやるべき3つ）

週次で“完成メモ”だけを残し、残りは破棄。**ノイズを溜めない勇気**が生まれます。

# 3段階の思考整理プロンプト
"言いたいことが多すぎて、まとまらない..."

1) 生メモ投下（断片OK）：時系列でそのまま

2) 3行要約（テーマ/主張/根拠）をAIに作らせる

3) ストーリー化（起/承/転/結）で読み物に変換

**書くことと整えることを同時進行**にすると、アウトプットの速度が上がります。

# 事例：議事メモが“意思決定の台本”に変わる
"議事録はあるのに、次に進まない..."

議論断片をAIに投入→論点マップ化→意思決定案3種→**各案のトレードオフ表**まで自動作成。会議翌朝には承認フローに回せる“台本”が完成します。

# まとめ：書きっぱなしを、今日で終わらせる
**メモは終点ではなく、中継地点**です。AIを組み込んだ循環で、思考は軽く、速く、深くなります。メモ帳を増やすのではなく、**行動の数**を増やしましょう。
