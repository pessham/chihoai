# AIに「時間」を食わせろ。あなたの思考プロセス丸ごと渡す「超入力術」

- 記事ID: 20250903

"考えがまとまる前に相談しても、ちゃんと伝わらない気がする..."

多くの人が、完成した指示だけをAIに渡そうとします。けれど、それではAIはあなたの脳内で起きている“途中経過”を理解できません。**AIに成果だけでなく「過程」を食べさせること**。これが、精度と速度を同時に上げる最短ルートです。

# なぜ「思考の途中」を渡すと精度が跳ね上がるのか
AIは、あなたの文脈・狙い・制約条件を学習しながら推論します。完成物だけを渡すと、**「なぜその判断に至ったのか」という因果の鎖**が欠落します。逆に、仮説→検討→迷い→暫定結論という流れをそのまま提示すれば、AIはあなたの評価軸を学び、次回以降の提案が驚くほど合致します。

# 「超入力術」の基本原則（時間を素材化する）
**原則1：時系列で渡す** — メモの断片を「時刻＋気づき」で並べるだけで十分です。

**原則2：揺れを残す** — 迷い・反対意見・ボツ案もそのまま残します。AIは差分から学びます。

**原則3：評価コメントを付ける** — 「ここは良い/悪い」「こう響かせたい」など、判定根拠を明示します。

# 具体例：企画書の“途中”をそのまま投げる
"タイトルが弱い気がする... でも、理屈は合っている..."

1) 09:10 仮タイトル案A/B/C（Aは強いが煽りすぎ、Bは安全だが印象が薄い）

2) 09:25 ペルソナの反応仮説（Aに刺さるのは30代管理職、Bは経営層）

3) 09:50 競合メッセージ比較（差別化軸：スピード/実装容易性/一次データ）

4) 10:15 自己評価コメント（Aの導入文は読み出しが重い。比喩を入れたい）

→ これをそのまま貼り、「上記の“流れ”を学習して、タイトルと導入を再設計」と指示します。**AIは「あなたの目線」を捕捉し、提案の粒度と言葉の体温が急に合ってきます**。

# 現場で効いたフォーマット（30分運用）
"とりあえず全部詰め込んでみた... 頭の中がうるさい..."

1) 00:00-05:00 ラフ思考吐き出し（時系列＋短文）

2) 05:00-10:00 自己要約（3行で要旨／判断基準／懸念）

3) 10:00-20:00 AIに渡す（「学習→提案→反論→改稿」のループを2回）

4) 20:00-30:00 最終整形（叩き台を人間の言葉に戻す）

この“30分パターン”を3日続けると、**AIとの共同作業は「委託」から「共創」へ変わります**。あなたの判断基準がAIの中に沈み込み、呼吸が合うのです。

# よくある失敗と回避策
"最後まで自分で考えてから渡すべきだ... まだ未完成だ..."

- 完成待ち症候群：未完の素材を出す勇気が持てない。→ 最初から「途中です」と宣言し、時系列で渡す。

- 情報過多：長文を一塊で渡してしまう。→ 見出し「時刻 / 事実 / 解釈 / 迷い」で分解。

- 正解依存：AIの一発回答に従う。→ 「反対案も3つ」必ず求め、**比較という摩擦**を作る。

# まとめ：時間をそのまま渡す勇気を
**AIの入力は“情報量”ではなく“時間量”で測る時代**です。未完成の思考を丸ごと渡すほど、AIはあなたの相棒になります。恥ずかしさを越えた人から、スピードも精度も別次元へ。今日の会議ノートから、試してみてください。
